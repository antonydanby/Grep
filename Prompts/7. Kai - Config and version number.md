# JSON Configuration

Please use the JSONConfig.pas file for all the following:

- Please add routines to the application to store
  - The screen resolution with the 
    - main forms position, height and width under this resolution
- When the application loads up it should automatically pick up this config
  - If the config does not exist it should create it in the same folder as the application
  - The lack of config should not cause an error
- When the application closes any changes to values that are on the config should be saved

# Version number

Please use the VersionInfo.pas for all the following:

- Please retrieve the version information 
  - Place it onto the caption of the main form
  - It should read something like "Jiggler - Version x.x.x.x"
    - Where x relates to the major, minor, release and build values found via TVersionInfo.FileVersion
